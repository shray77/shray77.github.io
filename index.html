02 · Архитектура

Как всё соединено

Экосистема — это конвейер: открытые источники текут в общую базу, продуктовые воркеры делают из них витрины, а хабы собирают всё в одном окне. Без серверов, в бесплатных лимитах.

📡

Открытые источники

Open-Meteo / ECMWF, METAR NOAA, WOAH WAHIS, ФСВПС Россельхознадзора, PubMed, RSS-ленты новостей

🛰

rss-core

инжест → нормализация → дедупликация → Cloudflare D1; статус каждого источника

⚙️

Воркеры-продукты

VetDigest (Workers AI), VetRecall (keyword-радар), BioThreat Watch (ИИ + гео-словарь), VetAPI (метео-срезы)

🪞

GitHub Actions → Pages

крон-мост: fetch → валидация → коммит JSON в публичные репы -site; работает из РФ без VPN

🖥

Хабы и модели

ВетХаб собирает витрины вместе; TimesFM, TSPulse, Qwen3, Piper — CPU-модели на раннерах Actions

Почему так: workers.dev заблокирован в РФ — поэтому вся пользовательская поверхность живёт на GitHub Pages (статика + коммиты данных), а Cloudflare остаётся чистым вычислителем за кулисами. Клиентский код всегда имеет фолбэк на закоммиченный JSON.

03 · Подход

Почему это работает

Три принципа, которые держат все восемнадцать проектов бесплатными и живыми.

📡

Открытые данные и код

Open-Meteo, METAR, открытые датасеты вспышек, FOSS-модели (Qwen, TimesFM, TSPulse, Piper, GigaAM). Никаких закрытых API — инструменты работают у любого ветврача без ключей и подписок. Каждый проект — публичный репозиторий с историей решений в ворклоге.

🐄

Практика важнее технологий

Каждый модуль родился из задачи в клинике, на ферме или в лаборатории: доза, каренция, зона риска, медкарта. Алгоритмы сверены с первоисточниками и нормативами (WOAH, приказы МСХ РФ). Модели проходят честную ретроспективу — и не выживают на витрине, если проигрывают простой статистике.

🧩

Экосистема, а не монолит

Каждый тул живёт своим репо, своим CI и своей частотой обновления. Git — это бекенд: воркеры коммитят JSON, витрины и хабы читают. Новый проект не ломает старые — он просто добавляет ещё один источник в конвейер и ещё одну плитку в хаб.
